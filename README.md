# cafe-landing

간단한 카페 랜딩 페이지 예제입니다. 순수 HTML/CSS로만 만들어졌고, 별도의 빌드나 설치 없이 바로 열어볼 수 있습니다.

## 폴더 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (상단 메뉴, 히어로, 대표 메뉴, 카페 소개, 오시는 길, 푸터) |
| `style.css` | 디자인 스타일 (색상 변수, 레이아웃, 모바일 대응) |
| `README.md` | 이 폴더에 대한 설명 |

## 실행 방법

`index.html` 파일을 브라우저에서 열면 됩니다.

## 수정 가이드

- 카페 이름, 메뉴, 가격, 주소, 전화번호는 예시 값이므로 `index.html`에서 실제 정보로 바꿔주세요.
- 색상은 `style.css` 맨 위의 `:root` 변수(`--brown`, `--cream`, `--dark`)에서 바꿀 수 있습니다.
